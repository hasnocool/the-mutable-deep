# Design Pillars

| Pillar | Meaning | POC proof |
|---|---|---|
| Living World | The simulation continues and reacts | jobs/needs/events tick without scripting every outcome |
| Mutable Characters | Characters change materially | injury + mutation changes capabilities |
| Shared World | Settlement and adventure share state | party enters actual fortress/cavern |
| Systemic Magic | Abilities alter systems | fire/water/web/stone interaction |
| Emergent Stories | History is generated from events | death/injury/faction event becomes history |
| Authored Adventure | Designed encounters still matter | one authored quest + dungeon |
| Player Agency | Multiple solutions are valid | combat, social, terrain, magic, stealth or preparation can matter |
