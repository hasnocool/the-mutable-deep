# Game Vision

## Working title

**The Mutable Deep**

## Genre

3D systemic fantasy simulation + colony/fortress management + party CRPG + procedural adventure sandbox.

## Player fantasy

The player builds a community in a dangerous layered world, develops memorable characters, takes a party into the same world, and watches the world react to what they do.

## Three scales

### World scale
settlements, travel, factions, regions, ecology, dungeons, history.

### Settlement scale
jobs, buildings, production, resource logistics, citizens, defenses, culture.

### Adventure scale
movement, dialogue, combat, exploration, quests, treasure, character progression.

All three modify the same underlying simulation.

## Core loop

```text
Observe → Decide → Designate/Act → Simulate → React → Adapt → Remember
```

## POC story test

1. Establish a small dwarf settlement.
2. Dig and construct an underground fortress.
3. Manage workers and resources.
4. Form a four-character adventuring party.
5. Explore a cavern below the fortress.
6. Fight a creature using D&D-like resolution.
7. Suffer an injury with persistent mechanical consequences.
8. Discover a mutable artifact or mutation.
9. Return to the settlement.
10. Trigger a faction or world event because of what happened.
11. See the consequences recorded in world history.
