# Character System

## Shared model

Citizens, adventurers, monsters and important NPCs use the same entity/component architecture.

```text
Identity
Species/Origin
Class
Level
Attributes
Skills
Traits
Body
Health
Needs
Equipment
Inventory
Abilities
Conditions
Memories
Relationships
Faction
```

## POC attributes

Strength, Dexterity, Constitution, Intelligence, Wisdom, Charisma.

## Skills

Mining, Crafting, Athletics, Acrobatics, Stealth, Perception, Survival, Medicine, Cooking, Arcana, Persuasion, Intimidation.

## Traits

Traits modify behavior and decision weighting: Brave, Greedy, Curious, Kind, Suspicious, Reckless, Disciplined, Claustrophobic.

## Memories

Memories are event-linked records with subject, emotional valence, strength and decay. Only important events need long-term persistence.
