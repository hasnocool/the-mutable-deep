# Phased Implementation Roadmap

The roadmap deliberately builds one complete vertical slice before expanding the world.

| Phase | Focus | Gate |
|---|---|---|
| 00 | Foundation | deterministic empty simulation |
| 01 | 3D world | walkable, editable voxel region |
| 02 | Fortress | autonomous settlement loop |
| 03 | D&D core | party-ready characters and rules |
| 04 | Adventure | functional CRPG dungeon/quest |
| 05 | Mutable | injuries, mutations, reactions |
| 06 | Integration | all pillars work in one world |
| 07 | Scale | benchmark-driven expansion |

Never start scale work before the prior phase's acceptance criteria pass.
