# Phase 04 — Adventure / CRPG

## Objective
Add the Neverwinter-style adventure layer without leaving the living simulation.

## Deliverables
Party movement, real-time-with-pause combat, dialogue graph, quest graph, dungeon POIs, traps, loot, merchant/NPC interactions and one authored adventure.

## Demo
Accept The Missing Miners, travel into the cavern, speak to an NPC, enter a dungeon, fight, loot, make a dialogue choice, and return.

## Exit criteria
The authored quest references real world entities and can be affected by simulation state instead of using a disconnected level instance.
