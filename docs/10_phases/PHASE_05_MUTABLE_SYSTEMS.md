# Phase 05 — Mutable Systems

## Objective
Introduce the Caves-of-Qud-inspired systemic character layer.

## Deliverables
Body parts, hit locations, injuries, capability changes, status effects, mutations, composable effects, material reactions, faction reputation, relationships and memories.

## Demo
A character is injured, loses access to a capability, acquires a mutation, uses an ability that changes terrain, and sees social/faction consequences.

## Exit criteria
At least five mutation/effect interactions work without bespoke quest scripts and survive save/load.
