# Phase 03 — D&D Character Core

## Objective
Make individual characters compelling enough to function as a CRPG party.

## Deliverables
Six attributes, d20 resolution service, skills, proficiencies, four classes, levels, equipment, conditions, party formation and character inspection.

## Integration rule
The rules service calculates checks and outcomes; the simulation applies physical/environmental consequences.

## Demo
Create four characters, inspect sheets, resolve skill checks and combat attacks, equip different weapons, and advance a character.

## Exit criteria
All combat/check outcomes are deterministic given seed + inputs and use shared character state rather than a separate RPG actor model.
