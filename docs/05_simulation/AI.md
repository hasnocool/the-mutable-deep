# AI

## POC decision model

Use lightweight utility scoring rather than LLM-driven control.

```text
Perceive → Generate Goals → Score Actions → Choose → Execute → Observe Result
```

Goals include hunger, sleep, safety, work, combat, socialization and curiosity.

## Action requirements

An action declares prerequisites, duration, target, interrupt rules and effects.

## Interruptions

Threats, path invalidation, injury, destination destruction, or higher-priority needs can interrupt work.

## Distance scaling

Future simulation LOD can reduce perception frequency, decision frequency and action detail for distant entities while preserving aggregate outcomes.
