# POC Acceptance Test

The POC passes when a new player can complete the following without developer intervention:

1. Generate a deterministic world.
2. Observe a surface + mountain + underground layers.
3. Designate and complete mining.
4. Build a room and stockpile.
5. Watch at least eight citizens choose and complete jobs.
6. Manage hunger/sleep/safety pressures.
7. Create a four-character party.
8. Enter the same cavern used by fortress simulation.
9. Fight a creature using d20-style checks.
10. Apply a body-part injury with capability consequences.
11. Gain/use a mutation or mutable ability.
12. Cast an environmental spell.
13. Complete/alter an authored quest.
14. Return to fortress.
15. Trigger or resolve an emergent faction event.
16. Record the consequences in history.
17. Save, reload and continue deterministically.

A screenshot/demo is not sufficient; the acceptance test must be observable through automated or reproducible state checks where practical.
